# v045 — 被否定的方向：QK 的 K 维跨两个 warp-group 拆分

本目录不产生成绩，保留它是为了印证技术方案第 8 节的结论。

## 做法

QK 原本是一串 32 条串行依赖的 MMA，只跑在 `T.ws(0)` 的 2 个 warp 上，另外 6 个 warp 空转。

把 K 维切成两半：`T.ws(0)` 算 K 属于 [0,256)，`T.ws(1)` 算 [256,512)，两组各 18 步并行，最后经共享内存相加。发射出的代码确认两组各跑 16 + 2 步。

## 结果

| ctx | 改动前 | 改动后 |
| --- | ---: | ---: |
| 16384 | 33.56 | 32.70 |
| 32768 | 52.15 | 53.59 |
| 65536 | 89.41 | 91.85 |

本地 16384 快 1.35 微秒，但判题机上 16384 的读数没有变化；同一改动在 32768 与 65536 上反而变慢。

## 结论

判题机在 16384 上是访存受限，不是算力受限。把每 tile 的 MMA 工作量减半，本地有效、判题机无效。

因此该档的最后 1 微秒只能靠减少字节或提高有效带宽，两者都已触及上限。
