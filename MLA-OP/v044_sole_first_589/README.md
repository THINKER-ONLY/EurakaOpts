## 相对 v043 的两处改动

两处均与该版基线逐字节一致（max|v-b| = 0）。

1. ctx=2048 路径的 `O_shared` 补 padding。v043 的旋转 skew 只覆盖 `main_split_pref`，短路径仍是 16 路 bank 冲突。补到 520 个 half 后 2048 从 15.42 微秒降到 13.64。
2. 到达自旋由 `atomic_add(State[0], 0)` 改为 `T.atomic_load`。MACA 上后者是普通 volatile load，不再有 RMW 争用，同时消掉掉队尾巴。

效果：2048 的判题读数由 0.013 变为 0.012，档位 96 升到 97。
