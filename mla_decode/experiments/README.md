# 实验脚本

优化过程中跑过的全部内核候选与微基准，按文件名前缀区分：

| 前缀 | 含义 |
| --- | --- |
| `vNNN_*.py` | 编号内核候选，多数是单点改动的 A/B 版本 |
| `probe_*.py` / `p_*.py` | 微基准与消融探针，用来测量单项成本 |
| `nsa_*.py` | native sparse attention 方向的试验（另一赛题） |
| `w*_*.py` | 针对特定瓶颈的一次性验证 |

这些脚本引用固定路径与本地环境，**不保证可直接运行**；可复现的最终版本见
`mla_decode/vNNN_*/submission.py` 与 `MLA-OP/`。
