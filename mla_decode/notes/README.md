# 研究笔记

本目录保存 MLA decode 优化过程中的一手记录，不是可提交的产物。

| 文件 | 内容 |
| --- | --- |
| `RESULTS.md` | 按时间顺序的实验记录与成本模型 |
| `PLAN_next.md` | 每轮的下一步计划与判题机行为记录 |
| `_findings.txt` | 零散结论速记 |
| `oj_ledger.jsonl` | 每次 OJ 提交的逐 case 判题原始数据 |
| `dsmla/` | 赛方参考实现与两个候选实现 |

判题机的计分规则、成本模型上限与已排除方向，见仓库根的 `docs/mla_decode_optimization_report.md`。
