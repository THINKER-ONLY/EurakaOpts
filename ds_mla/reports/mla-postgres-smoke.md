## Theoretical changes and limitations

DSH introduced balanced split boundaries, split/sequence-tail score masks, FP32 split LSE,
a reduction in redundant split-path shared-to-fragment transfer, fixed single-KV-head
indexing, and a dividing head tile. It also proposed two-stage pipelining and 256 threads
for the no-split path. Those scheduling choices are unbenchmarked and may regress on some
hardware. Arbitrary small head tiles and tail-copy lowering still need real compiler tests.

The active Python and all six inspected Conda environments lack an installed TileLang package;
no CUDA compiler was found on PATH, and the inspected local TileLang trees did not contain
the searched compiled TileLang/TVM libraries. The user-authorized theoretical-only fallback
was therefore used. No dependency installation, GPU compilation, numerical comparison, or
performance benchmark was performed. No measured acceleration is claimed.

Token/cost budgets remain advisory in this opted-in unmetered profile. Timeouts were enforced;
unknown usage values must not be interpreted as zero cost.
